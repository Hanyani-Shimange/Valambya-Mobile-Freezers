# Valambya Mobile Freezers

## 📌 Project Overview

Valambya Mobile Freezers is a responsive business website created to provide information about mobile freezer products and services. The website gives customers an easy way to learn about the business, view available services or products, and make enquiries.

The website uses a clean **blue and white colour scheme** to create a professional and refrigeration-related appearance.

## 🎯 Purpose of the Website

The main purpose of the website is to:

* Introduce Valambya Mobile Freezers to potential customers.
* Provide information about the business and its services.
* Display mobile freezer products or solutions.
* Make it easy for customers to contact the business.
* Provide a simple and user-friendly browsing experience.

## 🖥️ Technologies Used

The website was developed using:

* **HTML5** – Used to structure the webpages.
* **CSS3** – Used for styling, colours, layouts and responsiveness.
* **Visual Studio Code** – Used as the development environment.
* **GitHub** – Used to store and manage the project.

## 🎨 Design

The website uses a **blue and white colour palette**.

* **Blue** – Represents cooling, reliability and professionalism.
* **White** – Creates a clean and simple appearance.
* **Light blue** – Used for backgrounds and section highlights.
* **Dark blue** – Used for headings, navigation and the footer.

The website is designed to be simple, professional and easy for customers to navigate.

## 📄 Website Pages

The website can include the following pages:

1. **Home** – Introduces Valambya Mobile Freezers and highlights the main services.
2. **About Us** – Provides information about the business.
3. **Services** – Explains the services offered to customers.
4. **Products** – Displays mobile freezer products or solutions.
5. **Contact / Enquiry** – Allows customers to send enquiries and find contact information.

## 📱 Responsive Design

The website is designed to work on different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

CSS media queries are used to adjust the layout for smaller screens.

## 🚀 How to View the Website

To view the website:

1. Download or clone the project from GitHub.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation menu to move between the different pages.
